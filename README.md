# 👨‍💻 Mohamed Hamani | Portfolio

## 📖 About the Project

A responsive personal portfolio introducing Mohamed Hamani, a self-taught Junior Software Engineer and Full-Stack Developer based in Setif, Algeria.

The portfolio presents his background, technical skills, education, certificates, and selected software projects. Its code-inspired design uses syntax-colored styling for CV details, while project galleries let visitors browse screenshots in an interactive image viewer.

## 📌 Features

1. 👋 **About**
   - Professional introduction and background
   - Contact and GitHub links
   - Links to certificates and CV

2. 📄 **CV**
   - Contact information and location
   - Education and professional coursework
   - Featured project experience
   - Certificates and technical summary

3. 🚀 **Projects**
   - Featured desktop, API, and web projects
   - Project descriptions and technology stacks
   - Interactive screenshot galleries

4. 🎨 **User Experience**
   - Light and dark themes; your preference is saved in the browser
   - Responsive layout for desktop and mobile
   - Keyboard controls for the image viewer: Escape to close and arrow keys to navigate
